3 — Le serveur Hub

hub/scripts/create-admin.js

Un script en ligne de commande pour créer le premier compte admin du Hub. Comme l'inscription publique est désactivée par défaut (routes/auth), c'est le moyen de bootstrapper un admin. Il s'exécute en interactif dans le conteneur : 

docker compose -f docker-compose.hub.yml run --rm backend npm run create-admin

Le fichier entier :

#!/usr/bin/env node
import readline from 'node:readline';
import argon2 from 'argon2';
import { config } from '../config.js';
import { openRegistry, getUserByEmail, insertUser } from '../registry.js';

const rl = readline.createInterface({ input: process.stdin, output: process.stdout });
const ask = (q) => new Promise((resolve) => rl.question(q, resolve));

async function main() {
  const db = openRegistry(config.dataDir);
  console.log('=== Création du compte admin Kapsule Hub ===\n');

  const email = (await ask('Email : ')).trim();
  if (!email) { console.error('Email requis.'); process.exit(1); }

  const existing = getUserByEmail(db, email);
  if (existing) { console.error(`Un compte existe déjà pour ${email}.`); process.exit(1); }

  const password = (await ask('Mot de passe : ')).trim();
  if (password.length < 8) { console.error('Le mot de passe doit faire au moins 8 caractères.'); process.exit(1); }

  const name = (await ask('Nom (optionnel) : ')).trim() || null;
  rl.close();

  const password_hash = await argon2.hash(password, { type: argon2.argon2id });
  insertUser(db, { email, password_hash, name, role: 'admin' });
  console.log(`\nCompte admin créé pour ${email}.`);
}

main().catch((err) => { console.error(err.message); process.exit(1); });
JS Le shebang #!/usr/bin/env node

La première ligne #!/usr/bin/env node est un shebang : sous Unix, elle indique quel interpréteur exécute le fichier s'il est lancé directement (./create-admin.js). /usr/bin/env node trouve node dans le PATH. Identique au #!/usr/bin/env python3 que tu connais. Ici le script est de toute façon lancé via npm run create-admin, donc le shebang est surtout une convention.

JS readline — lire l'entrée clavier

Le module readline lit les saisies au clavier (process.stdin). Son API est à callback : rl.question(prompt, callback). Le script la promisifie pour pouvoir l'utiliser avec await : 

const ask = (q) => new Promise((resolve) => rl.question(q, resolve));
// puis : const email = await ask('Email : ');

On retrouve le même motif que partout (envelopper un callback dans une Promise — voir checksum.js). Résultat : une fonction main async lisible, où chaque await ask(...) attend la saisie de l'utilisateur.

Le déroulé

  1. Ouvre le registry (crée la base si besoin).
  2. Demande l'email ; refuse si vide ou déjà utilisé (process.exit(1) = sortie en erreur).
  3. Demande le mot de passe ; refuse si < 8 caractères.
  4. Demande un nom optionnel (… || null : chaîne vide → null).
  5. Hache le mot de passe avec argon2 et insère l'utilisateur avec role: 'admin'.
JS main().catch(...) — gérer l'échec d'une fonction async

Une fonction async retourne une Promise. Pour attraper une erreur au niveau racine (il n'y a pas de await englobant), on chaîne .catch() : main().catch((err) => { console.error(err.message); process.exit(1); }). Si quoi que ce soit lève dans main, on affiche le message et on sort avec un code d'erreur. process.exit(1) termine le processus (≈ sys.exit(1) / os.Exit(1)) ; 0 = succès, non-zéro = erreur.
