Qu'est-ce que Kapsule ?

Une borne vidéo pour événements (mariages, soirées…). Deux moitiés :

  • La Borne — un Raspberry Pi posé sur place, avec un iPad en mode kiosque. Les invités enregistrent une vidéo en réponse à des questions. 100 % hors-ligne : tout est stocké localement, rien ne dépend d'Internet pendant l'événement.
  • Le Hub — un serveur (VPS) où le client (l'organisateur) prépare son événement à l'avance, puis récupère les vidéos après. La Borne se synchronise avec le Hub quand elle a du réseau (avant / après l'événement).

Les deux sont des serveurs Node.js + Express avec des bases SQLite, et des interfaces web React (servies en statique). Le tout dans un monorepo géré par les workspaces NPM.
